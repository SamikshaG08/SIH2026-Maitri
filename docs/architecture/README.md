# Planned Architecture

```text
React Frontend
      |
      v
REST API
      |
      v
Node.js + Express
      |
      v
MySQL Database
      |
      v
AI/ML Layer
      |
      v
Predictions / Alerts / Analytics
```

The frontend will present the Figma-defined workflows. The backend will own validation and domain workflows. MySQL will store operational records, while the AI/ML layer will consume approved and documented environmental datasets for future analysis.
