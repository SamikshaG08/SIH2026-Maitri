# AI/ML

This area is reserved for future analysis and machine learning work using approved NCPOR Maitri datasets.

- `notebooks/`: exploratory analysis and experiment notebooks
- `preprocessing/`: reproducible data preparation steps
- `src/`: reusable analysis and model code
- `models/`: generated model artifacts when the team approves a model lifecycle
- `predictions/`: generated outputs for downstream analytics or alerts

Planned tooling includes Python, pandas, NumPy, scikit-learn, and Jupyter. No fake models or predictions are included.
