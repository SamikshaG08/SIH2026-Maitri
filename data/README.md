# Data

This area will hold approved Maitri datasets and their documented processing history.

- `raw/` contains original NCPOR datasets exactly as received.
- `processed/` contains cleaned or transformed datasets produced by documented steps.
- Never modify the original dataset in `raw/`.
- NCPOR / the National Polar Data Centre must be properly credited as the data source.
- Do not commit sensitive, restricted, or unnecessarily large files.

No external datasets are downloaded automatically by this repository.
